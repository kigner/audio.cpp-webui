# audio.cpp Windows portable v0.6.0

This stable release combines audio.cpp 0.6 and the upstream changes through
`04ba437` with the downstream Windows WebUI and updater distribution.

## Highlights

- Added five model families: DotTTS, NeuTTS, MuScriptor, MiniMax-H3, and
  SenseVoice, bringing the catalog to 49 model families and more than 70 model
  variants.
- Shipped the upstream native WebUI beside the local Python/Gradio WebUI as an
  independent entry point, including native model install, progress, cancel,
  remove, and server-side model unload workflows.
- Extended the local WebUI for the v0.6 backend contracts, including MuScriptor
  MIDI output, SenseVoice offline/streaming ASR, MiniMax-H3 audio output, and
  the newly exposed streaming TTS families and sample-rate profiles.
- Added expanded GGUF/package support, including Qwen3-TTS 0.6B packages,
  IndexTTS-2.5, shared codec/flow/transformer runtimes, and additional CUDA and
  Metal optimizations.
- Made local-WebUI model downloads persistent across retries and WebUI restarts,
  deduplicated aliases that resolve to the same package, adopted compatible
  legacy partial downloads, and added an interprocess package lock.

## Windows builds

- CPU core: AVX2
- CUDA core architectures:
  `61-real;75-real;86-real;89-real;120a-real;90-virtual`
- Updated executables: `audiocpp_cli`, `audiocpp_server`, and `audiocpp_gguf`
- Python environment changes: none
- CUDA runtime DLL changes: none
- Updater version: 1.1.1

## Updating

Run `update.bat` from an existing updater-enabled Windows portable
installation. The stable channel updates directly to v0.6.0; no intermediate
release is required.

- Supported source versions: `0.2.0` and later
- Verified direct-upgrade matrix: `0.2.0`, `0.2.1`, `0.2.2`, `0.3.0`,
  `0.4.0`, `0.4.1`, `0.4.2`, `0.5.0`, and `0.5.1` to `0.6.0`
- Updated components: `app`, `core-cpu`, and `core-cuda`

Portable releases older than 0.2.0 did not include the current updater
contract. Those installations require the one-time updater bootstrap before
they can use the stable channel.

The updater preserves downloaded models, custom voices, generated output, API
keys, logs, UI language preferences, and SpeakType configuration. If
validation fails, managed files are restored from `_update\backup\`.
