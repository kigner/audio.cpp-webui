# SpeakType 全局语音录入

SpeakType 是 Aixora Studio 的 Windows 语音输入工具。打开听写后，可以直接把说的话输入到记事本、聊天框或编辑器中。悬浮条会显示录音状态和识别文字。

## 开始使用

1. 双击整合包根目录的 `run_webui.bat`，打开 Studio。
2. 进入 **场景应用 → 全局语音录入**，选择已安装的流式识别模型、语言和麦克风。
3. 启动语音录入，等待悬浮条出现。Studio 会自动准备识别服务。
4. 点击你要输入文字的位置，再按页面显示的快捷键开始听写。
5. 说话时稍作停顿，识别完成的文字会输入到目标窗口。再按一次快捷键停止录音。
6. 结束使用时，在 Studio 的场景页面停止语音录入。

整合包已包含所需依赖，无需单独安装或启动 ASR 脚本。

## 快捷键与输入

- 使用 **Studio 页面显示的快捷键**，按一次开始，再按一次停止。实际组合键由 `SpeakType/config.json` 中的 `hotkeys.toggle_recording` 决定；修改后需重新启动语音录入。
- **Esc**：取消当前还未提交的片段。
- 开始前先点击目标输入框。悬浮条不会抢走输入焦点。
- 如果识别完成前切换了窗口，文字会保留在剪贴板中；回到需要的位置，按 **Ctrl + V** 粘贴即可。

## 设置与日志

麦克风、快捷键等设置保存在 `SpeakType/config.json`。运行日志在 `SpeakType/logs/app.log`。

需要手动修改配置时，先停止语音录入，再修改对应选项：

| 配置项 | 用途 |
|---|---|
| `hotkeys.toggle_recording` | 开始和停止录音的快捷键 |
| `ui.click_through` | 开启后，鼠标可以穿过悬浮条点击后面的窗口 |
| `injection.restore_clipboard` | 粘贴识别文字后恢复原来的纯文本剪贴板内容 |

## 常见问题

- **没有识别文字**：检查所选麦克风、Windows 麦克风权限，以及 Studio 中的识别模型是否已加载。
- **文字没有输入到窗口**：先点击输入框再开始；如果期间切换过窗口，检查剪贴板并手动粘贴。
- **快捷键没有反应**：检查是否与其他程序冲突，修改后重新启动语音录入。
- **启动失败**：在 Studio 查看识别服务状态，并查看 `SpeakType/logs/app.log`。
