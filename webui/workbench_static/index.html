手机访问

用手机与电脑上的语音助手通话，角色、声音和模型都在电脑上设置。

保存实时语音中当前选用的角色与设置；修改后再次保存，下次手机通话时生效。

  1. 手机与电脑连接同一 Wi-Fi，用相机扫码并轻点链接。
  2. 首次出现证书警告时，核对地址是这台电脑，选择“显示详情／高级 → 继续访问”。
  3. 打开通话页，点击“开始通话”，允许麦克风访问。

地址打不开时，请检查电脑防火墙是否允许 Python 通过专用网络。更换网络后，关闭再开启此开关以刷新地址。
