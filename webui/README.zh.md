# Aixora Studio 使用说明

> **语言 / Language:** [English](README.md) · **中文**

Aixora Studio 是一个本地音频工作空间，可以生成语音、识别录音、制作音乐、处理声音，也可以进行实时语音聊天和视频翻译配音。

## 启动与退出

1. 完整解压整合包，双击根目录的 **`run_webui.bat`**。
2. 等待浏览器打开，或手动访问 `http://127.0.0.1:7899`。整合包启动器使用 **7899** 端口；自行修改过端口时，以启动信息显示的地址为准。
3. 在模型中心安装需要的模型，进入功能页，选择模型并点击 **加载**，然后输入文字或上传素材。
4. 用完后，在 **系统设置 → 退出工作空间服务** 中退出，也可以运行 `run_webui.bat --stop`。

关闭浏览器后，后台服务会继续运行。再次双击 `run_webui.bat` 即可打开界面。

在 **系统设置 → 外观 → 界面语言** 中可切换中文或 English，浏览器会记住选择。启动语音录入时，SpeakType 悬浮条也会使用所选语言。

整合包已包含 Python 和运行依赖，无需另外安装。请保留完整目录结构。随包模型见根目录的使用说明，其他模型可在模型中心下载。

## 常用功能

| 页面 | 可以做什么 |
|---|---|
| 语音合成 | 把文字读出来，克隆参考录音的声音，或边生成边播放 |
| 语音识别 | 把录音转成文字，查看时间戳和说话人信息 |
| 音乐与音效 | 用提示词、歌词或原始音频生成、编辑声音 |
| 声音设计 | 描述想要的音色，生成并试听 |
| 声音转换 | 给说话声或歌声换一种音色 |
| 场景应用 | 制作字幕、给视频翻译配音、实时语音聊天、全局语音录入 |
| 参考音频 | 保存参考声音和录音原话，供声音克隆等功能使用 |
| 音频工具 | 分离音轨、增强声音、降噪、分析和转换格式 |
| 模型中心 | 查找、下载和删除模型 |
| 系统设置 | 切换外观、查看运行中的模型和日志、退出服务 |

选择模型后，页面会显示它支持的语言、输入方式和设置。第一次使用可以保留默认参数；带 **需重载** 标记的设置改好后，点击 **应用并重载模型**。

声音克隆需要一段清晰的参考录音。页面要求参考文本时，填写录音里的原话；要生成的新内容填在合成文本框。生成后可在结果区试听、查看详情和下载文件。

**已安装**表示模型文件已下载，**已加载**表示模型已准备好运行。**卸载模型**释放内存和显存，**删除模型文件**释放磁盘空间。下载中断后，可以在模型中心继续下载。

## 实时语音聊天

1. 打开 **场景应用 → 实时语音聊天**。
2. 在聊天设置中填写对话服务地址、模型名和 API Key。服务需兼容 Chat Completions 接口，可以使用本地或云端服务。
3. 选择角色、声音模型、音色、识别模型和麦克风，再选择交流语言。
4. 保存后点击麦克风，允许浏览器录音，即可开始对话。也可以直接输入文字。
5. 点击停止或左上角返回结束通话，麦克风会同时关闭。再次开麦时会继续使用已加载的对应声音模型。

交流语言选 **自动** 时，回复会跟随你说的语言；也可以指定一种交流语言。请同时选择支持该语言的声音模型。

## 全局语音录入

打开 **场景应用 → 全局语音录入**，选择已安装的流式识别模型并启动。随后切换到记事本、聊天框或其他输入框，按页面显示的快捷键开始听写，再按一次停止。

Studio 会自动启动识别服务和悬浮条。结束使用时，从场景页面停止语音录入。

## 外观与设置

默认外观为 **经典蓝紫＋浅色**。在系统设置中可以改用石墨琥珀、深色或跟随系统。你已经保存的选择会继续沿用。

Studio 支持中文和英文界面。外观及部分聊天设置保存在当前浏览器中，更换浏览器或端口后需要重新设置。

## 更新与常用文件

更新前结束任务和通话，退出工作空间服务，再双击根目录的 **`update.bat`**，按提示完成更新。

日常只需要运行 `run_webui.bat` 和 `update.bat`。`_env.bat` 与 `webui/start_webui.bat` 是启动时自动调用的文件，请保留，无需单独打开。

| 位置 | 内容 |
|---|---|
| `models/` | 已安装的模型 |
| `webui/voice/` | 参考声音及对应文本 |
| `webui/output/` | 生成结果和场景项目 |
| `webui/logs/` | 启动和运行日志 |
| `SpeakType/config.json` | 全局语音录入设置 |
| `_update/backup/` | 更新时保存的备份 |

迁移到新电脑时，复制整个整合包目录即可保留这些文件。浏览器中保存的外观和聊天设置需要在新电脑重新填写。

## 选择显卡或 CPU

启动器会按 **CUDA → Vulkan → CPU** 的顺序选择可用后端。使用显卡前，请安装显卡厂商提供的驱动。

需要手动选择时，先退出 Studio，在整合包目录打开命令提示符，输入：

```bat
set AUDIOCPP_BACKEND=vulkan
run_webui.bat
```

也可以把 `vulkan` 改为 `cuda` 或 `cpu`。

## 常见问题

- **打不开界面**：查看 `webui/logs/startup.log`，或运行 `run_webui.bat --diagnostic` 查看启动信息。
- **端口被占用**：先退出 Studio，检查是否有其他程序占用 **7899** 端口。需要更换端口时，修改根目录 `run_webui.bat` 中的 `AUDIOCPP_UI_PORT` 设置，重启后使用新地址。在终端设置同名环境变量不会覆盖该启动器内指定的值。
- **实时聊天没有识别文字**：检查浏览器麦克风权限、输入设备和识别模型。
- **有识别文字但没有回复**：检查对话服务地址、模型名和 API Key。
- **有回复但没有声音**：检查声音模型是否加载、是否支持当前语言，以及播放器和系统音量。
- **显存不足**：在系统设置中卸载闲置模型，或缩短输入、换用较小的模型。
- **更新后仍是旧页面**：退出服务后重新启动，再刷新浏览器。
